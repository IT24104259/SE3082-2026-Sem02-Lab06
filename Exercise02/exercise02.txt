#pragma omp single specifies that the enclosed block of code should be executed by exactly one thread from the team - whichever thread reaches it first - while all the other threads skip the block entirely and wait. This is different from master (Exercise 3) because the executing thread is not necessarily thread 0; it could be any thread in the team, and this can vary between runs. By default, single includes an implicit barrier at the end of the block: all other threads must wait at that point until the single-executing thread finishes, before any thread continues to the "Hi again" line. This guarantees the single block's output is not interleaved with the following code.
