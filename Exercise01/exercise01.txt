A barrier is a synchronization point that forces every thread in the parallel region to pause and wait until all threads in the team have reached the same point, before any of them are allowed to proceed further. In this program, each thread executes printf("thread # %d\n", th) independently and at different speeds. The #pragma omp barrier acts as a checkpoint: no thread is permitted to execute the code after the barrier (the "Outside Barrier" print) until every other thread has also arrived at the barrier. This is why the output cleanly separates into two phases - all "before barrier" output, then all "after barrier" output - even though thread execution order within each phase is non-deterministic. Note that (since a cluster with qsub was not available in this setup) the program was executed directly on an AWS EC2 instance via SSH instead, which produces the same OpenMP synchronization behaviour.
